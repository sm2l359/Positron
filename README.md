# Positron
A hand-made Just-In-Time text editor developed entirely with VB.NET and cefsharp, while it was originally made to handle svg projects, this editor also happens to support html/css/js, and many others.

Basic info:
development started back in 2024 as a utility project
to help the developer with other projects.

and eventually gained it's space as a small open source
editor in github.


Trivia:
-the project is constantly
getting into hiatus due to
frequent pauses to work
on other projects.

(so do not expect some huge
level of consistency between
releases.)

-currently Positron only finds itself in the alpha stages.
all versions prior to 1.70 only recieved private releases.
